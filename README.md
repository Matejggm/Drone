Autonomous STM32 Drone

An experimental 3.5-inch autonomous cinewhoop designed around an STM32 flight controller.

The goal of this project is to build a precise and reliable drone while learning low-level embedded programming, electronics, control systems, and Edge AI.

Main goals

- Design a custom STM32-based flight controller PCB
- Develop low-level C/C++ firmware and real-time control
- Implement sensor fusion using an IMU and barometer
- Develop PID-based attitude stabilization
- Test and optimize motors, propellers, and power systems
- Explore TinyML for autonomous decision-making
- Build a reliable system under strict weight and hardware limitations

This project is developed from the ground up, with measurements and experiments documented throughout the process..
